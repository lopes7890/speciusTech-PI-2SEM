# 🚀 Specius Tech — PI 2º Semestre DSM

Site da equipe **Specius Tech**, desenvolvido como Projeto Integrador (PI) do 2º semestre do curso de **Desenvolvimento de Software Multiplataforma (DSM)** da **Fatec**.

🔗 **Acesse o site:**
- [Vercel](https://speciustech-pi-2sem-main.vercel.app)

---

## 📌 Sobre o projeto

O site apresenta a equipe Specius Tech e o trabalho desenvolvido ao longo do semestre no Projeto Integrador.


## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Deploy: Vercel

## ▶️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/lopes7890/speciusTech-PI-2SEM.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd speciusTech-PI-2SEM/main
   ```
3. Abra o arquivo `index.html` no navegador, ou use a extensão **Live Server** do VS Code para recarregar automaticamente a cada alteração.
